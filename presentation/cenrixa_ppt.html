Factor 1: Authentication

keycloak_auth Package

Identity Verification Engine

  • Protocol Compliance: Full implementation of OpenID Connect (OIDC) and OAuth 2.0 standards.
  • Security Validation: Recursive verification of RSA-signed JWT tokens using live JWKS key sets.
  • Stateless Design: Enables horizontally scalable session management across distributed server nodes.
  • Profile Extraction: Seamless parsing of token claims into application-level credential models.

The Auth Federator Handshake

Identity Brokerage between Providers and Platform

Okta / Google (IDP)
➔
KEYCLOAK (Broker)
➔
CENRIXA (Backend)

Keycloak acts as a Identity Broker. It redirects the User to their preferred provider (Okta/Google), receives the signed identity response, and issues a CENRIXA-standard JWT for application use. This allows for unified SSO across disparate enterprise environments.

Factor 2: Authorization

rbac_system Package

Access Governance Matrix

  • Resource Logic: Categorizes system functionalities as Resources (e.g., tasks, reports).
  • Action Scoping: Defines specific verbs (create, read, approve) per individual resource.
  • Permission Mapping: Atomic linking of roles to specific Resource:Action permissions.
  • Defense In-Depth: Every API request is guarded by an internal check_permission() logic trap.

Role Profile: Administrator

System-Level Governance

  • Manage global roles and system-wide permission mappings.
  • Access infrastructure-wide audit logs and security trace history.
  • User lifecycle oversight and administrative identity management.
  • Configuration of global project parameters and resource definitions.

Role Profile: Manager

Operational Orchestration

  • Creation, assignment, and management of training task modules.
  • Formal review and quality validation of Trainee evidence submissions.
  • Performance monitoring and progress tracking of assigned user sets.
  • Authority to trigger state-machine transitions (Review -> Approval).

Role Profile: Trainee

Execution & Learning

  • Direct access to assigned task backlog and training materials.
  • Upload and submission of progress evidence for quality review.
  • Real-time visualization of personal certification milestones.
  • Self-service progress tracking toward training completion.

Factor 3: Orchestration

taskflow_system Package

Workflow Automation Engine

  • Deterministic Logic: Enforces strict state transitions that cannot be bypassed manually.
  • Event Auditing: Automatically logs every status flip and actor identity for full history.
  • Modular Design: The workflow logic is independent of the business layer for clean scaling.
  • Data Integrity: Guarantees that no task enters 'Completed' status without formal verification.

The Task State Machine

BACKLOG
IN_PROGRESS
UNDER_REVIEW
COMPLETED

CENRIXA's orchestration layer ensures that every unit of work moves through a pre-defined quality funnel. The system prevents a task from moving directly from In Progress to Completed, mandating a formal Review action by a Manager-level authority.
